## What I work on

Two intersecting disciplines, one habit of mind: make the data trustworthy, then
make it useful.

| | |
|---|---|
| **Data Engineering** | Batch and streaming pipelines, dimensional modelling, orchestration, and the testing/observability layer that keeps them honest. Airflow, dbt, Spark, Terraform, Docker. |
| **Analytics & BI** | Semantic layers and reports that answer business questions instead of restating the database. Power BI, DAX, dbt Semantic Layer, Metabase. |
| **AI Engineering** | Agent systems built on deterministic graphs rather than free-form autonomy — LangGraph, FastAPI, LLM providers behind explicit interfaces. |
